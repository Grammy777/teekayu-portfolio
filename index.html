ผมทำครบทุกขั้นของงานระบบ ตั้งแต่เก็บ requirement จนถึงทดสอบกับลูกค้า ใน 3 โ⁠ป⁠ร⁠เ⁠จ⁠ก⁠ต⁠์ลูกค้าจริง

  1. Requirementเก็บความต้องการ
  2. Specเขียน SRS · ออกแบบ
  3. Buildbackend · เชื่อมระบบ
  4. Testทดสอบกับลูกค้า

  1. Requirement

    Behn Meyer TMS / Shipping Hub · ระบบติดตามการขนส่ง web + mobile

    เข้าประชุมกับลูกค้า เก็บ requirement ได้กว่า 100 รายการ จาก 5 กลุ่มผู้ใช้: บริษัทขนส่ง, Admin, เซลล์, ลูกค้า และคนขับ

  2. Spec

    Behn Meyer TMS / Shipping Hub · ระบบติดตามการขนส่ง web + mobile

    เขียน SRS 69 Functional Requirements พร้อม BPMN swimlane ออกแบบหน้าจอ web/mobile และทำเอกสารแปล UI ภาษาอังกฤษ 157 รายการ

  3. Spec

    ระบบคำของบประมาณและติดตามผล · กระทรวงการพัฒนาสังคมและความมั่นคงของมนุษย์

    ร่วมเขียน SRS 5 ระบบย่อย (คำของบประมาณ, ติดตามการเบิกจ่าย, e-Inspection, PA-OPS, PMQA) วิเคราะห์ระบบเดิมบน AppSheet และออกแบบหน้าจอ PA-OPS

  4. Build

    Behn Meyer TMS / Shipping Hub · ระบบติดตามการขนส่ง web + mobile

    คำนวณ CO2 จากการขนส่งตาม Emission Factor ของ TGO (องค์การบริหารจัดการก๊าซเรือนกระจก) ตาม ISO 14060 เชื่อมต่อ SAP, CRC และ GHG API ติดตามรถด้วย Mapbox และเก็บรูปภาพใน MinIO

    Go · PostgreSQL · MinIO · Mapbox

  5. Test

    M-NSC · ระบบบริหารการประชุม web + iPad

    ทดสอบการประชุมทั่วไปและการประชุมลับ การส่งข้อความถึงผู้เข้าประชุม การ login ด้วย Thai ID ลายน้ำ และการล็อกเอกสารก่อนเวลา แล้วบันทึกปัญหาและติดตามการแก้ไขร่วมกับลูกค้า
